# Go Todo APP
Basic Todo app to test Go and htmx using default stdlib html/templates

## Stack Description 
- Router: [Chi Router](https://go-chi.io/)
- DB: [SQLite](https://www.sqlite.org/)
- Js: [HTMX] (https://htmx.org/)
- Css: [PicoCss](https://picocss.com/)

## How to run it

Install go lang if you dont't have it,
cd into the project dir
and simply exec

```
go run *.go 
```

have fun!
